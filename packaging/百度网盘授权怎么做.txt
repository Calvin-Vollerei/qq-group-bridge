========================================================
 百度网盘授权怎么做（这一步稍微专业一点，让帮你配置的人看）
========================================================

为什么需要这一步：
    本程序不直接对接百度网盘，而是通过一个叫 OpenList 的中转小工具。
    OpenList 需要用一份"授权令牌"（refresh token）才能读写你的百度网盘。

    这份令牌必须在浏览器里登录百度账号、点一次"同意授权"才能拿到，
    没法用账号密码代替。

    ⚠️ 令牌等于百度网盘的钥匙，**不要发给任何人、不要发到群里**。


--------------------------------------------------------
 准备
--------------------------------------------------------
· OpenList（中转工具）已经在运行（本程序启动时会自动拉起它）
· 浏览器（Edge / Chrome 都行）
· 百度网盘账号（要收到文件的那个账号，登录时用）


--------------------------------------------------------
 第 1 步  打开 OpenList 网页后台
--------------------------------------------------------
浏览器打开：

        http://127.0.0.1:5244

· 首次使用需要设置管理员密码：如果启动日志里给过初始密码就用它，
  或者用命令 `openlist.exe admin set 新密码` 重设一个。
  这个用户名/密码就是稍后要填进本程序「网盘与凭据」页的那一对。

· 登录后左侧能看到「存储」「用户」等菜单。


--------------------------------------------------------
 第 2 步  获取百度网盘的 refresh token
--------------------------------------------------------
1. 在浏览器**新开一个标签页**，打开：

        https://api.oplist.org/

2. 页面上选「百度网盘」
3. 点「获取 token」按钮
4. 会跳到百度的登录/授权页面 → 用**要收文件的百度账号**登录 → 点「同意」
5. 页面会显示一长串结果，找到 **refresh_token** 这一项，
   点它右边的复制按钮

   ⚠️ 百度网盘**只保留最新一个**令牌：
      每次点「获取 token」，旧的那份就失效了。
      所以复制之后要**立刻**粘贴保存，中间不要再点第二次。

   ⚠️ 别把这段内容发给我以外的人；讲完之后请把剪贴板清掉。


--------------------------------------------------------
 第 3 步  在 OpenList 里添加百度网盘
--------------------------------------------------------
1. 回到 http://127.0.0.1:5244 的「存储」页
2. 点「添加」
3. 填写：
        驱动      ：选「百度网盘」
        挂载路径  ：/baidu          （本程序默认按 /baidu/你的子目录 存放）
        启用      ：开
        使用在线 API（Use online api）：开
        Refresh token ：粘贴第 2 步复制的那串
4. 点「保存」

5. 检查状态：存储列表里这一行的状态应该是「工作」（work）。
   如果显示错误，看它后面的提示文字：
        · 「empty token returned from official API」→ 令牌没粘全，重新获取
        · 「invalid refresh token」→ 令牌过期或被新令牌顶掉了，重新获取


--------------------------------------------------------
 第 4 步  确认本程序里的路径对上
--------------------------------------------------------
回到本程序 →「网盘与凭据」页：

        WebDAV 地址    ：http://127.0.0.1:5244/dav
        远端根目录     ：/baidu/QQ群备份
                          （要和上面的挂载路径 /baidu 对得上）

点「测试连接」，看到成功即可。

如果报 403（无权限）：
    到 OpenList 的「用户」页编辑你的账号，把「WebDAV 管理」权限勾上再保存。


--------------------------------------------------------
 常见问题
--------------------------------------------------------
问：令牌多久失效？
答：正常情况下不需要重新获取。但如果你在别处又点过一次「获取 token」，
    这份就立刻失效了，必须重新获取并粘贴。

问：能不能直接用百度网盘账号密码？
答：不行。百度没有开放这种接口，必须走授权令牌。

问：收到的文件在哪个文件夹？
答：百度网盘的 /我的应用数据 下的对应目录里，或你挂载路径指定的位置。
    见本程序「网盘与凭据」页显示的远端根目录。

问：能换一个百度账号吗？
答：可以，但要重新做第 2、3 步（用新账号的令牌），并且旧账号里的文件不会搬过去。
