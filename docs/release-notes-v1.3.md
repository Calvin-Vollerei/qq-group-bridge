## QQ群文件搬运工 v1.3

本版按用户实测反馈改了三处行为：**二维码不再"点了没反应"**、
**下载顺序与筛选可以自己掌控**、**一个下载失败不再拖住整批**。

---

### 下载哪个

| 文件 | 说明 |
|---|---|
| `qgb-v1.3-full.zip` | **推荐**。主程序 + NapCat 组件，解压即用（52 MB） |
| `qgb-v1.3-app-only.zip` | 只有主程序，NapCat 由你自行下载安装（22 MB） |
| `QQ群文件搬运工-解压我.zip` | 面向零基础用户的交付包：包名与目录全中文，内含《第一步看这里》《百度网盘授权怎么做》两份图文说明 |

**不需要安装 Python**：主程序自带 Python 3.11 运行时。系统要求 Windows 10/11 x64。

### 本版改了什么

**① 一个下载失败，不再拖住后面的文件**

- 原行为：失败的文件被退回「待处理」，而遍历用的是本轮开始时的快照 ——
  于是**队首那个坏文件被立刻重新处理**，连续吃满重试次数（默认 3 次），
  它后面的文件一直排不上队；
- 现在：**同一批内先跳到下一个文件**，下次循环再回来重试它
  （重试退避由循环间隔自然实现）。失败仍会被记录、稍后自动重试，不会丢文件。

**② 文件列表：排序 + 搜索 + 置顶/上下移**

监控页 →「📋 文件列表 / 下载顺序」，一个表管到底：

- **顶部排序**：按「下载顺序 / 文件名 / 群号 / 大小 / 上传时间 / 处理时间」，
  可切「倒序」；**点列标题**同样能排序；
- **搜索框**：输入文件名或群号即时筛选（边打边筛）；
- **★置顶 / 取消置顶 / ↑上移 / ↓下移**（双击也能置顶）：只对「待处理」的行生效，
  已搬完的行会自动提示并禁用；
- 顺序规则：**置顶 → 我排的顺序 → 没排过的按发现时间**；上移下移**不越过置顶边界**；
- **改完立即生效**：搬运线程每处理完一个文件就重新取队列，不用重启监控。

**③ 二维码「点了刷新不了」—— 根因是程序把它静默丢弃**

- 单次取码最长等 25 秒，而二维码约 30 秒失效，用户必然连点；
- 旧逻辑对"同名任务在跑"直接返回失败，**界面在失败时什么都不做** → 看起来像没反应；
- 现在：**新的请求取代旧的**（旧结果自动丢弃），点击后**立刻**显示
  「正在获取二维码…（最长等 25 秒）」并置忙按钮；失败文案追加"可以再点一次重试"。

**④ 下载卡住不再久等**

- 原来靠 requests 的读超时（60 秒）兜底：服务器接了连接却不再发数据时，
  要等满 60 秒才报错，再乘重试次数 —— 实测**105 秒**才轮到下一个文件；
- 现在把**读超时收紧为「卡死阈值」（默认 20 秒）**，同样场景 **5 秒**内放弃并继续；
- 阈值可在**高级页 →「下载卡死阈值（秒）」**调整（最低 5 秒）。

**⑤ 顺带修掉的两个自身缺陷**

- `scripts/recover-napcat.py`（组件恢复工具）读 WebUI 配置时**少拼了一层 `config/`**，
  导致每次运行都重新生成令牌 → 切回界面又报「令牌无效」。已改为读旧值原样写回；
- NapCat 的登录限流阈值从默认 3 次/分钟放宽到 10 次/分钟（配置期不再一点就限流）。

### 重要提醒

- 本包**不含**任何凭据、群号、网盘账号；凭据只在本机用 Windows DPAPI 加密保存
- 本包**不含**腾讯客户端二进制，QQ 运行环境由 NapCat 官方安装器在首次启动组件时下载
- NapCat 是非官方 QQ 客户端，**请用专用小号**，保持默认轮询间隔；账号风险自担
- 未做代码签名，首次运行可能被 SmartScreen / 杀毒软件拦截，选「允许」即可
- OpenList 的百度驱动有**单文件 2 GB 上限**，群里有超大文件时请把「最大体积」设为 1900 MB
- 电脑需保持开机不休眠；关机后重新双击 `启动搬运工.bat` 并点「开始监控」即可，
  已搬运的文件有去重记录，不会重复上传
- **升级旧版本时**：解压覆盖即可，**不要动 `data\` 目录**（凭据、群号、NapCat 运行时都在里面）；
  状态库会自动升级（新增排序列），旧数据不丢

### 已知问题

- NapCat 组件首次启动必须能访问外网；无法离线安装 QQ 运行环境
- 百度网盘只保留最新一个 refresh token，重复获取会让旧的失效
- 若「获取二维码」提示登录过于频繁，等 60 秒再点一次即可
- 本项目未启用云端 CI：它是 Windows 专用工具，所有闸门在本机执行
  （361 项单元测试 + 离线端到端冒烟 + 源码扫密 + 界面结构检查）
