# v2.0 — 全新界面（PySide6）+ 托盘 + 缓存管理

> 这是一个大版本。界面从头重写，功能一次性补齐，另外修掉了几个会白耗流量/磁盘的真问题。

## 界面全面重写（PySide6 / Qt 6）

旧版 Tk 界面换成 **PySide6**，窗口带**原生毛玻璃模糊**（Windows Aero 材质），深色单主题、对比度按可读性调优。

五个页面全部重做，并把旧版功能**逐项对齐**（不是简化版）：

| 页面 | 内容 |
|---|---|
| **监控** | 开始/暂停/停止/立即刷新、6 项指标、进度条、**运行日志**（级别着色 + 清空/导出/打开日志文件）、**文件列表与下载顺序** |
| **群与规则** | 群号增删、网盘目录名映射、**按群名一键生成**、正则过滤（包含·排除）、**常用模板**、**规则试跑**、扩展名/体积限制 |
| **QQ 登录** | 组件启停、**从压缩包安装**、二维码登录、连接参数、令牌加密保存、**打开 NapCat 网页版** |
| **网盘与凭据** | 上传方式、WebDAV 配置、凭据加密保存、**连接测试**、**OpenList 状态/启动/停止/打开后台**、凭据一览与清除 |
| **高级** | **11 项运行参数**、环境自检、打开数据/日志/临时目录、**窗口与托盘**、**本地缓存** |

> 旧界面仍可用：`QQGroupBridge.exe --ui tk`

## 关闭时缩到托盘

点关闭按钮会询问「**直接关闭** / **缩小到托盘**」，可勾选"记住我的选择"。

- 托盘菜单：显示主界面 / 立即刷新 / 退出程序
- 缩到托盘后**继续在后台搬运**，双击托盘图标恢复
- 设置里可选：每次询问 / 直接进托盘 / 直接退出，也可整体关闭托盘功能

## 本地缓存管理

- 显示**当前缓存**占用与文件数
- **🧹 一键清除本地缓存**（不影响已上传文件、不影响去重记录）
- **缓存保留天数 0～30**（默认上传成功即删；设为几天可避免"想再传一次"时重新下载）

## 永久排除任务（省流量）

文件列表里可把**永远搬不上去**的文件永久排除：

- **⛔ 永久排除选中**
- **永久排除全部筛选结果**（一键清掉当前筛选里的"失败/已过期"）
- **管理永久排除…**（查看名单，可一键全部恢复）

排除后不再出现在列表、不再重试、不再下载，重新扫描也不会再纳入。

## 修掉的几个真问题

| 问题 | 说明 |
|---|---|
| **14 GB 磁盘垃圾** | 上传失败的文件被反复重新下载（同一个 582MB 文件下了 129 次）。现在：直链过期只清残片、本地已有完整副本则跳过下载、每轮清理陈旧临时目录 |
| **405 被误判为临时故障** | 网盘持续拒绝时（授权失效/配置错误）会无限重试并反复重下大文件。现在连续 5 次即熔断并给出排查清单；任一次成功即清零 |
| **-134 取不到下载直链** | 该文件已被删除或权限变更，重试无意义。现在直接判永久失败 |
| **打包后界面空白** | 页面构造逻辑未接入导致所有标签页是空壳 |
| **日志栏没有输出** | 日志被写进一个隐藏控件；现在写入用户可见的日志卡 |
| **交付 exe 启动即崩** | 动态导入的页面模块未打包进 exe |

## 安装

1. 下载 `qgb-v2.0-app-only.zip`，解压到任意目录（**不要**放到中文路径下的深层目录）
2. 双击「启动搬运工.bat」
3. 按界面提示完成 **群号 / 网盘 / QQ** 三步配置

> 升级：把新包解压覆盖旧目录即可；**不要删除 `data\` 目录**（里面有你的配置与凭据）。

## 环境

- Windows 10 / 11（64 位）
- 需要 OpenList 作为 WebDAV 中转（本程序可代为启停）
- 需要 NapCat 组件（本程序可代为下载安装）
