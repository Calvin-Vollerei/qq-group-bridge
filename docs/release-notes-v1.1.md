## QQ群文件搬运工 v1.1

把指定 QQ 群里的**新文件自动抓取、过滤，并上传到网盘**的 Windows 桌面工具。
本次是面向"零基础用户交付"的版本：程序功能未变，但补齐了从解压到跑通的全部文档。

---

### 下载哪个

| 文件 | 说明 |
|---|---|
| `qgb-v1.1-full.zip` | **推荐**。主程序 + NapCat 组件，解压即用（52 MB） |
| `qgb-v1.1-app-only.zip` | 只有主程序，NapCat 由你自行下载安装（22 MB） |
| `QQ群文件搬运工-解压我.zip` | 面向零基础用户的交付包：顶层目录与文件名全中文，内含《第一步看这里》《百度网盘授权怎么做》两份图文说明 |

**不需要安装 Python**：主程序自带 Python 3.11 运行时。系统要求 Windows 10/11 x64。

### 三步上手

1. 解压到**短路径**（如 `D:\QGB`），双击 `启动搬运工.bat`
2. 「QQ 登录」页 →「启动组件」（首次会联网下载约 300 MB 的 QQ 运行环境，**必须联网**，没有进度条属正常）→「获取二维码」→ 用**小号**手机 QQ 扫码
3. 「网盘与凭据」页 → 填 OpenList WebDAV 地址与账号 →「测试连接」→「监控」页点「开始监控」

> 完整的零基础流程见交付包里的《第一步看这里.txt》；
> 网盘授权那一步（取 refresh token）见《百度网盘授权怎么做.txt》。

### v1.1 相对 v1.0 的变化

- **新增面向零基础用户的文档**：《第一步看这里》（一页纸流程 + 三条底线 + 排障顺序）、
  《百度网盘授权怎么做》（OpenList 取 refresh token 的分步说明、403 权限、令牌只保留最新一个）
- **新增交付包**：`QQ群文件搬运工-解压我.zip`，包名/目录名全中文，
  「自检.bat」改名为「出错了点这个.bat」（对非技术用户是行动指令）
- **新增 `scripts/upload-release.ps1`**：用 `curl.exe` 直传 Release 附件
  （PowerShell 的 `Invoke-RestMethod` 在部分网络环境下会断；
  且 `-w`/`-o`/参数数组传给 curl 会被拆错，脚本已避开这三样）
- **程序内部版本号** 0.1.0 → 1.1.0，界面「关于」里显示一致
- README 的下载段不再写死版本号，改为 `qgb-<版本>-*.zip`
- 修复：`LocalUploader` 在 Linux 语义下会把正常远端路径判成越界
  （仅影响本地目录适配器，WebDAV 不受影响）

### 重要提醒

- 本包**不含**任何凭据、群号、网盘账号；凭据只在本机用 Windows DPAPI 加密保存
- 本包**不含**腾讯客户端二进制，QQ 运行环境由 NapCat 官方安装器在首次启动组件时下载
- NapCat 是非官方 QQ 客户端，**请用专用小号**，保持默认轮询间隔；账号风险自担
- 未做代码签名，首次运行可能被 SmartScreen / 杀毒软件拦截，选「允许」即可
- OpenList 的百度驱动有**单文件 2 GB 上限**，群里有超大文件时请把「最大体积」设为 1900 MB
- 电脑需保持开机不休眠；关机后重新双击 `启动搬运工.bat` 并点「开始监控」即可，
  已搬运的文件有去重记录，不会重复上传

### 已知问题

- NapCat 组件首次启动必须能访问外网；无法离线安装 QQ 运行环境
- 百度网盘只保留最新一个 refresh token，重复获取会让旧的失效
- NapCat 的 PacketBackend 按 QQ 版本定制；若遇到「不支持当前QQ版本架构」，
  请用自带运行时的包（本项目的完整包即是），而不是挂钩自己新装的 QQ
- 本项目未启用云端 CI：它是 Windows 专用工具，所有闸门在本机执行
  （328 项单元测试 + 离线端到端冒烟 + 源码扫密）
